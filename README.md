# KBO 시뮬레이터

Claude 를 사용한지 불과 1달...
저는 이제 Claude 없이는 살 수 없는 몸이 되어 버렸습니다.
토큰을 다 쓰기라도 하는 날에는 
나라 잃은 사람처럼 허망한 마음을 달랠 길이 없었죠.

토큰은 왜 몇 번 쓰지도 않았는데 모자란지.
왜 토큰 세션은 시작 시간을 기준으로 5시간이고
심지어 주간 한도는 세션 시작을 기준으로 일주일을 계산하는지.   

그러다가 문득
안쓰고 남겨진 지난 일주일 동안의 토큰이 생각났습니다.

이제 Anthropic 에게 복수하는 방법은
일주일 토큰을 모두 소진하는 것 뿐.

이 프로젝트는 100% 바이브 코딩으로 개발합니다.
개발자가 현업에 치여서 토큰이 안 남으면 개발 속도는 느려질 수 있습니다.

요즘 야구 게임은 재미가 없습니다.
뭔가 보여드리겠습니다.
