# KBO 시뮬레이터

Claude 를 사용한지 불과 1달...
저는 이제 Claude 없이는 살 수 없는 몸이 되어 버렸습니다.
토큰을 다 쓰기라도 하는 날에는 
나라 잃은 사람처럼 허망한 마음을 달랠 길이 없었죠.

그러다가 문득
안쓰고 남겨진 지난 일주일 동안의 토큰이 생각났습니다.

이제 Anthropic 에게 복수하는 방법은
일주일 토큰을 모두 소진하는 것 뿐.

이 프로젝트는 100% 바이브 코딩으로 개발합니다.
개발자가 현업에 치여서 토큰이 안남으면 개발 속도는 느려질 수 있습니다.

요즘 야구 게임은 재미가 없습니다.
뭔가 보여드리겠습니다.

## 개발 계획

로스터
- KBO 로스터 수집
- 선수별 능력치 평가 (AI + 시즌별 성적)
- 로스터 확인 페이지

성장 시스템
- 잠재력(1-9) 및 전성기 나이 평가 (AI)
- 새 게임 생성 시 잠재력 임의 생성 기능
- 선수 성장/노쇠화 로직 구현
- 전성기 구간 및 한계 능력치 변동성 추가
- 훈련 캠프 / 2군 시스템 추가

게임 플레이
- 경기 일정 생성
- 경기 로스터 제출
- 시뮬레이션
- 경기 결과 반영
